# Корпоративный каталог промптов

Проект создаёт внутренний портал для хранения и распространения промптов. Основная цель — предоставить сотрудникам удобную навигацию, единый формат описания и быстрый доступ к текстам промптов.

## Стек

- Python 3.11+
- MkDocs + Material for MkDocs
- mkdocs-macros-plugin, mkdocs-awesome-pages-plugin
- Docker (multi-stage) + Nginx

## Структура репозитория

- `docs/` — контент портала: главные страницы и каталог промптов.
- `js/prompt-variables.js` — кастомный JavaScript для работы с копированием и будущими переменными.
- `assets/logo.svg` — логотип.
- `mkdocs.yml` — конфигурация сборки.
- `Dockerfile` — сборка статики и образа с Nginx.
- `requirements.txt` — зависимости для сборки.
- `TODO.md` — дорожная карта развития.
