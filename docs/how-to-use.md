# Как пользоваться каталогом промптов

Каталог построен на базе MkDocs Material и оптимизирован для внутреннего использования. Следуйте инструкциям ниже, чтобы быстро находить и применять нужные шаблоны.

## Поиск и навигация

- Используйте левое меню или глобальный поиск, чтобы найти нужную категорию или промпт по ключевым словам.
- Внутри каждой категории промпты отсортированы по тематике.

## Работа с промптом

1. Откройте карточку промпта.
2. Ознакомьтесь с назначением и инструкциями по применению.
3. Нажмите кнопку **Copy** в блоке с текстом промпта — содержимое скопируется в буфер обмена.
4. Вставьте текст в выбранную LLM и при необходимости адаптируйте результат.
