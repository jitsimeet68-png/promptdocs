## Назначение

Промпт помогает собрать структурированный анализ рыночных конкурентов для подготовки коммерческих предложений и стратегических сессий.

## Как использовать

1. При необходимости укажите значения переменных `company_name` и `market`.
2. Скопируйте блок промпта нажатием на кнопку **Copy**.
3. Вставьте результат в LLM и следуйте рекомендациям модели.

## Шаблон промпта

```prompt
Ты — аналитик рынка.
Подготовь структурированный анализ конкурентов.

Компания: {{company_name}}
Рынок: {{market}}

Структурируй ответ по пунктам:
1. Основные конкуренты
2. Продукты и услуги
3. Ценовое позиционирование
4. Сильные и слабые стороны
5. Рекомендации для {{company_name}} на рынке {{market}}.
```
