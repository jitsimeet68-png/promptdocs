# Корпоративный каталог промптов

Добро пожаловать во внутренний портал компании для работы с промптами. Здесь собраны проверенные шаблоны для задач продаж, маркетинга, аналитики, разработки и поддержки.

## Возможности каталога

- навигация по категориям и тегам;
- единый формат описания промптов;
- удобное копирование текста промпта прямо со страницы;
- дальнейшее развитие — заполнение переменных и генерация итогового текста.

## Быстрый старт

1. Изучите раздел [Как пользоваться](how-to-use.md) — там описаны основные действия.
2. Перейдите в нужный раздел каталога.
3. Откройте страницу промпта и скопируйте текст одним кликом.
4. Используйте шаблон в любимой LLM (ChatGPT, Claude и т.п.).
